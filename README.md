# ⚖️ Posbakum (Sistem Informasi Pos Bantuan Hukum)

Platform website sistem informasi Pos Bantuan Hukum (Posbakum) berbasis Laravel dan MySQL yang dirancang untuk mempermudah masyarakat dalam mengakses layanan konsultasi hukum, pengajuan permohonan bantuan hukum, serta pengelolaan data perkara dan administrasi posbakum secara online.

---

## 🛠️ Tech Stack (Teknologi yang Digunakan)
- **Backend:** PHP, Laravel
- **Database:** MySQL
- **Frontend:** Blade Templating, Tailwind CSS / Bootstrap
- **Version Control:** Git & GitHub

---

## 🌟 Fitur Utama
1. **Layanan Pengajuan Bantuan Hukum:** Memungkinkan masyarakat/pemohon untuk mengunggah berkas dan mengajukan konsultasi atau bantuan hukum.
2. **Manajemen Berkas & Perkara (CRUD):** Admin/Petugas Posbakum dapat mengelola data pemohon, status verifikasi berkas, serta jadwal konsultasi.
3. **Dashboard Informasi & Edukasi Hukum:** Menampilkan informasi seputar alur pelayanan hukum, syarat pengajuan, dan berita/edukasi hukum.
